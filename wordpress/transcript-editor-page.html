The Techspressionism Archive's transcripts are machine-generated and contain errors — wrong words, mis-heard names, the occasional misattributed speaker. If you were part of a recording, or just have a good ear, you can help fix it.

How it works

  1. Open the recording on the archive and find “Download transcript as” near the top of the page. Choose TXT (for editors).
  2. Open the file in any text editor. Each turn has a timecode before the speaker's name, like [00:06:12] Name — these are for reference only and won't appear on the site.
  3. Edit the wording freely: fix typos, mis-heard words, punctuation. If a speaker's name is wrong, correct it on that line. Please leave the timecodes and paragraph breaks exactly as they are — that's how your edits get matched back to the recording.
  4. The Synopsis and Participants sections at the top are for context only; edits there aren't applied.
  5. Save the file and send it back using the form below.

Every edit is reviewed before it goes live — nothing is published automatically.
